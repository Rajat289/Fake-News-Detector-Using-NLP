# 📰 Fake News Detector Using NLP

## 📌 Overview
The Fake News Detector Using NLP is a machine learning project that classifies news articles as real or fake using Natural Language Processing techniques. It helps identify misleading or false information automatically.

---

## 🚀 Features
- Text preprocessing (tokenization, stopword removal, stemming/lemmatization)
- Feature extraction using:
  - Bag of Words (BoW)
  - TF-IDF
- Machine learning models for classification
- Model evaluation using accuracy, precision, recall, and F1-score
- Easy-to-use prediction system

---
